How it actually works

Clicking the bookmark runs a script inside the tab you already have open that drops a small peeking icon fixed to the edge of the screen. Click the icon and a panel opens showing whichever flavor matches the site you're on — right now just YouTube's combined theme + scroll flavor. Click the bookmark again (or the icon again) to close the panel; it stays loaded on the page either way, and your theme choice is remembered for next time via this browser's local storage.

The bookmark itself is a tiny, permanent loader — it fetches the current flavor code fresh from flavors.waleeds.world every time you click it, then runs it. That means updates to the flavor system go live instantly for everyone using this bookmark; you never need to reinstall it. Source lives at github.com/Majboor/bookmarklet-flavors.
